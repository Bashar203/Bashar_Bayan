Bashar & Ameertoh - Engagement Invitation
==========================================

Files:
- index.html: two-page responsive invitation website.
- page1.jpg: approved first page image (kept as-is).
- page2.jpg: the newly supplied second-page artwork, cropped only below the gold invitation frame to remove the printed/static countdown. The card artwork itself is unchanged.
- whatsapp-preview.jpg: B wax-seal preview image for Open Graph link previews.

Deployment:
1. Extract all files into the ROOT of the existing GitHub repository Bashar_Bayan.
2. Keep the filenames exactly as provided.
3. Commit and push to the existing main branch / GitHub Pages root.

Features:
- First-page open button switches to page two.
- Small back arrow returns to page one.
- The map button is a transparent clickable area over the map button printed on the second-page image.
- A live countdown updates every second to 8 December 2026, 5:30 PM Amman time (+03:00).
- Falling petals are animated in CSS/JS.
- WhatsApp preview uses the B seal image via absolute Open Graph URL.

Note: WhatsApp caches link previews. After publishing, allow time for its cache to refresh; if needed, use the WhatsApp Sharing Debugger / Meta Sharing Debugger where available.
