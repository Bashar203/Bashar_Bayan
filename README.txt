Bashar & Bayan invitation website

Upload these files directly to the ROOT of your GitHub repository (main / root):
- index.html
- invitation-artwork.jpg

No assets folder is used. Keep both files side by side.

Typography update:
Arabic: Aref Ruqaa (family names and main titles), Amiri (Quranic verse and elegant Arabic details), Tajawal/Cairo (supporting text).
English: Playfair Display (editorial headings), Cormorant Garamond (countdown and elegant details), Montserrat (small labels), Great Vibes (B seal).

Google Fonts are loaded online, so an internet connection is needed for the selected font files. The page includes fallback fonts.
No music is included.
