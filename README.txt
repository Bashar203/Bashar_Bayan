طريقة النشر:
1) ارفع كل الملفات الموجودة داخل هذا المجلد إلى جذر مستودع Bashar_Bayan على الفرع main.
2) لا تغيّر أسماء الملفات.
3) اترك GitHub Pages مضبوطاً على main / (root).
4) افتح https://bashar203.github.io/Bashar_Bayan/

ملاحظات:
- صور الدعوة الأصلية نُسخت كما هي دون قص أو تعديل أو إعادة ضغط.
- الصفحة الأولى تظهر أولاً. النقر على زر "افتح الدعوة" ينقل للصفحة الثانية.
- في الصفحة الثانية توجد منطقة ضغط شفافة فوق زر الخريطة المرسوم بالصورة، وتحت الصورة عداد حي وتفاصيل فعلية ورابط خريطة.
- لا يوجد زر مشاركة داخل الموقع.
- صورة واتساب تحتاج أن يكون الموقع منشوراً حتى تتمكن واتساب من جلبها من رابط Open Graph.
